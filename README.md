# GreenCom

Адаптивная главная страница GreenCom по макету Figma.

- Демо: https://nevmewss.github.io/greencom/
- Исходный код: https://github.com/nevmewss/greencom

## Локальный запуск

```bash
npm install
npm run dev
```

## Сборки

```bash
npm run build
npm run build:pages
```

`npm run build` создаёт основную Vinext-сборку, а `npm run build:pages` —
статическую версию для GitHub Pages. Публикация GitHub Pages запускается
автоматически после каждого обновления ветки `main`.
