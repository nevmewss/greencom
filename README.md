# GreenCom

Готовый React/Vinext-фронтенд и отдельная headless CMS на Laravel, Filament и PostgreSQL.

Текущая вёрстка не переносилась и не изменялась. CMS находится в каталоге `backend`, чтобы после получения полного ТЗ подключить данные к существующим React-компонентам без переделки визуальной основы.

## Что подготовлено

- четыре существующие страницы: главная, «Про нас», «Контакты» и 404;
- Laravel 13 API и Filament 5 по адресу `http://localhost:8000/admin`;
- PostgreSQL 18 в Docker;
- мультиязычность с украинским, русским и английским языками, выбором основного языка и возможностью добавлять другие;
- отдельные заголовки, SEO-поля и контент для каждого языка;
- визуальный конструктор из секций, которые реально присутствуют в вёрстке: первые экраны, преимущества, услуги, блок «Про нас», партнёры, новости, контакты, рассылка, достижения, команда, история, офис, карта, FAQ, форма и 404;
- добавление, копирование, сортировка, скрытие и удаление блоков и вложенных элементов;
- отдельные редактируемые поля каждого типа секции и возможность добавлять/удалять карточки услуг, преимуществ, новостей, сотрудников, этапы истории, вопросы FAQ, логотипы и другие повторяемые элементы;
- загрузка и редактирование изображений через CMS с сохранением путей к уже используемым изображениям вёрстки;
- публичные API: `GET /api/locales`, `GET /api/pages` и `GET /api/pages/{slug}`.

Нужный язык передаётся параметром `locale`, например:

```text
GET http://localhost:8000/api/pages/home?locale=ru
```

Если параметр не указан, API отдаёт основной активный язык.

## Локальный запуск

1. Запустите Docker Desktop.
2. Поднимите CMS и базу:

   ```bash
   docker compose up --build
   ```

3. В отдельном терминале запустите существующий сайт:

   ```bash
   npm install
   npm run dev
   ```

Локальный вход в CMS:

- URL: `http://localhost:8000/admin`
- email: `admin@greencom.local`
- пароль: `change-me-before-production`

Это локальные реквизиты. Перед публикацией их нужно заменить через переменные окружения `CMS_ADMIN_EMAIL` и `CMS_ADMIN_PASSWORD`.

## Следующий этап

После полного ТЗ сопоставляем существующие блоки четырёх React-страниц с данными API. Разметка и CSS остаются основой сайта; меняется только источник текстов, изображений и повторяемых элементов.
